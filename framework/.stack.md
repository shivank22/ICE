## Languages / frameworks

- gateway: FastAPI (Python 3.12+)

- knowledge-service: FastAPI (Python)
- agent-orchestrator / skill-loader: FastAPI + LangGraph + Deep Agents (Python); may colocate early, keep API boundaries
- sandbox-provisioner: FastAPI (Python)
- finops-engine: FastAPI (Python)
- adaption-engine: FastAPI (Python)

- mcp: Python MCP SDK → gateway HTTP
- cli: Python Typer → gateway HTTP

## Platforms

- auth: OAuth 2.0 / OIDC via Microsoft Entra ID (gateway JWT validation; web auth code + PKCE)
- datastore: Azure Database for PostgreSQL Flexible Server + pgvector
- skill_registry_traces: Langfuse (Prompt Management labels draft/staging/production + LLM/agent tracing)
- orchestration: LangGraph + Deep Agents
- llm: OpenAI (prefer Azure OpenAI deployments; record model names below when fixed)
- message_bus: Azure Service Bus
- runner_backend_phase1: docker
- runner_backend_phase3: k8s (AKS) via SandboxBackendProtocol
- cloud: Azure
- email_transport: Microsoft Graph  # Phase 5
- secrets: Azure Key Vault
- workspace_store: Azure Files / Blob
- infra_telemetry: Application Insights
